# 메이커 안전미션

기술실 · 무한상상실 · 메이커실 · 융합형 교육실에서 실습 전에 안전한 행동을 확인하는 초·중·고 학습용 웹게임입니다.

## 사용 방법

1. **도구 선택하고 시작하기**를 누르고 이번에 사용할 도구를 고릅니다. 여러 개 또는 전체 선택할 수 있습니다.
2. 공통 안전미션 6문항과 선택한 도구별 3문항에서 안전한 행동을 선택합니다.
3. 문제를 해결하면 숫자 단서가 공개됩니다. 마지막에 모은 숫자 4자리를 입력합니다.
4. 완료 후 이번 활동의 안전수칙을 확인합니다.

이전·다음 문항 버튼으로 해결한 문제와 해설을 다시 볼 수 있습니다. 다시 보기는 **첫 선택에 해결** 기록과 답변 횟수를 변경하지 않습니다. **풀던 문항으로 돌아가기**로 이어서 진행할 수 있습니다.

시간 제한은 없습니다. 틀린 문제는 설명을 읽고 다시 선택할 수 있습니다. 도구 19가지, 전체 63문항이며 도구 하나를 선택하면 총 9문항입니다.

## 개인정보와 실행

설치·로그인 없이 실행됩니다. 이름과 연락처를 입력하지 않으며 진행 기록은 사용하는 브라우저에 저장됩니다. 시작 화면의 **미션 이어하기**로 계속할 수 있습니다. 파일을 내려받아 `index.html`을 열면 오프라인으로도 사용할 수 있습니다.

## 참고자료와 이미지 안내

「학교내 무한상상실 안전매뉴얼」 2022년 개정판을 참고해 문항을 새로 작성했습니다. 각 미션 아래에 참고한 쪽수를 표시합니다.

이미지는 생성형 AI로 만든 학습용 가상 장면입니다. 일부 형태나 배치가 실제 실습 환경과 다를 수 있습니다. 실제 실습에서는 해당 도구·장비의 안전수칙과 지도교사의 지도를 따라 주세요. 게임 완료가 실제 장비 사용 자격을 뜻하지는 않습니다.
